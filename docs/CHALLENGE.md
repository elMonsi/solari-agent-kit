# Solari Hiring Challenge

> Source: [@getsolari tweet](https://x.com/getsolari/status/2094459417357930820) · Repo: <https://github.com/solari-sdk/solari-cookbook>

## The offer

Solari is hiring a **Software Engineering intern for Pinetree Research** at a **$300K annualized** salary. Instead of a resume or grades, they want to see something you *built*.

## What they ask you to do

1. **Fork** the Solari repo (the [solari-cookbook](https://github.com/solari-sdk/solari-cookbook)).
2. **Build a real use case** with Solari — using its cloud **browsers**, **sandboxes**, or **desktops**.
3. **Publish it publicly** on GitHub.
4. **Share it** on LinkedIn or X, **tagging** the relevant accounts.
5. Using **AI tools** to build it is explicitly encouraged.

They say they'll review builds, schedule interviews, and may **hire on the spot** for a good fit. Closing line: *"May the best dev win 🚀"*.

## How to win (my read)

The bar isn't "run the example." The examples are ~40 lines each and run in under a minute. The differentiator is a **genuine, non-trivial use case** that stitches Solari's primitives together into something that clearly works end-to-end against the real API — ideally combining products (e.g. a computer-use/agent loop that browses, runs code in a sandbox, and previews the result). Make it public, clean, and demoable.
